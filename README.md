# Время маникюра

Адаптивный сайт студии на Next.js App Router, TypeScript, Tailwind CSS и Lucide. Каталог услуг опубликован **без цен**. Фирменные материалы взяты из `Content`; оригиналы сохранены.

Текущая версия: **2.0.0**, Git-тег `v2.0.0`.

## Запуск

Требуется Node.js 20.9+ (разработка и проверки выполнены на Node.js 24).

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Если порт занят: `npm run dev -- --port 3001`.

Production:

```bash
npm run build
npm run start
```

Проект подходит для хостинга с поддержкой Next.js/Node.js. Внешняя база данных не требуется.

## Что работает

- Sticky header, якорная навигация, мобильное меню с Escape и закрытием при выборе раздела.
- Три вкладки каталога: маникюр, наращивание и педикюр. Доступны стрелки клавиатуры, Home и End.
- Кликабельные номера телефона, запись через контакты, переход в Яндекс Карты.
- Плавающая кнопка звонка с учётом safe area и измеряемой высоты cookie-баннера.
- Выбор `all` / `necessary` в `localStorage` под ключом `vm_cookie_consent`, повторное открытие в footer, синхронизация между вкладками. Аналитики нет.
- Страница `/privacy`: явно обозначенный проект документа, без выдуманных реквизитов и собственных форм сбора данных.
- Семантическая разметка, один H1 на страницу, JSON-LD, OpenGraph, локальные шрифты, адаптивные WebP через `next/image`.
- Поддержка `prefers-reduced-motion`, клавиатурного фокуса и перехода к содержимому.

## Настройка перед размещением

Скопируйте `.env.example` в `.env.local` и задайте `NEXT_PUBLIC_SITE_URL` равным настоящему домену. Затем выполните новую сборку. После этого автоматически появятся canonical, абсолютные OpenGraph URL и запись главной страницы в sitemap. Пока домен не указан, sitemap пустой: фиктивных адресов в нём нет.

### Яндекс Карты

Карта встроена по умолчанию и загружается автоматически при прокрутке к контактам. Организация `216353023162` и координаты `37.657299,55.741408` проверены по исходной короткой ссылке заказчика: это карточка «Время маникюра», Таганская улица, 1/2с2. Ключ API не требуется.

В бесплатном виджете Яндекс может показывать рекламу или резервировать место под неё. Отключение рекламы требует соответствующего тарифа и API-ключа Яндекса; для собственного компактного окна с деталями точки потребуется переход на JavaScript API. Используется стандартный виджет.

Чтобы заменить карту, откройте нужную точку в Яндекс Картах → «Поделиться» → «Встроить карту», скопируйте **только значение `src`** из официального iframe и укажите в `NEXT_PUBLIC_YANDEX_MAP_EMBED_URL`. Поддерживаются HTTPS URL `yandex.ru/map-widget/...` и `yandex.com/map-widget/...`. После изменения пересоберите проект.

Кнопка «Построить маршрут» рядом с кнопкой звонка открывает карту отдельно, в том числе если встроенный виджет блокируется браузером. Дополнительная дублирующая ссылка под картой убрана. Карта оформлена молочно-бронзовой рамкой.

### Часы в логотипе

`AnimatedLogo.tsx` сохраняет исходную руку и бронзовую рамку и накладывает SVG-циферблат на место растрового. Три стрелки показывают московское время, обновляясь раз в секунду. При возвращении во вкладку время синхронизируется заново. Исходный WebP не изменён. Яркость существующей подсветки по краю монеты плавно меняется через маску исходного изображения; отдельное светящееся кольцо не рисуется. Арка вокруг логотипа убрана. В шапке и подвале используется статичный логотип. При `prefers-reduced-motion` пульсация отключается.

### Фотографии и визитка

В блоке «О студии» макет заказчика подписан как визуальная концепция. Он не выдаётся за фотографию готового салона. Галерея скрыта до добавления реальных фотографий в массив `interiorImages` в `InteriorGallery.tsx`; файлы помещаются в `public/images/`.

`DiscountCardSection` по умолчанию отключён. Для включения передайте `enabled`, `image`, `discount`, `terms` и при необходимости `validUntil`. Процент скидки и срок действия заранее не заданы.

### Политика и аналитика

Перед публичным запуском владелец должен заполнить реквизиты и сведения о фактической обработке данных на `/privacy`, проверить документ и убрать статус проекта после согласования. Сведения о журналах хостинга зависят от выбранной площадки.

Если в будущем появится аналитика, подключайте её только при выборе `all`, проверяя сохранённый выбор при запуске и слушая событие `vm:consent-changed`. При `necessary` скрипты и дальнейшая отправка событий должны прекращаться. Событие само по себе никакую аналитику не запускает.


Результаты ручных браузерных проверок — в `QA.md`. Оценка Lighthouse не замерялась.

```bash
node scripts/prepare-assets.mjs
```

Исходники должны оставаться в `Content` под текущими именами.
